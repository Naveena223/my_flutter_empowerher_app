# EmpowerHer 💜

**Financial Freedom For Every Woman**

EmpowerHer is a beautifully designed Flutter application dedicated to empowering women by providing them with the necessary tools and knowledge to achieve financial independence. The app offers a seamless user experience, starting with a secure OTP-based authentication system, and provides a centralized platform for learning, saving, tracking sales, and getting AI-powered financial tips.

🌐 **Live Demo:** [https://empowerher-v1.web.app/](https://empowerher-v1.web.app/)

## ✨ Features

- **Sales Tracking:** Easily manage and track your business or personal sales.
- **Learn:** Access curated educational resources to enhance your financial literacy.
- **Savings:** Utilize tools designed to help you manage, plan, and grow your personal savings.
- **AI Tips:** Receive smart, personalized financial advice powered by Artificial Intelligence.
- **Secure Authentication:** A smooth onboarding experience featuring Email/Password and OTP (One-Time Password) sign-in options.

## 🚀 Getting Started

This project is a starting point for a Flutter application. To run this app locally:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-link>
   ```

2. **Navigate to the project directory:**
   ```bash
   cd my_flutter_empowerher_app
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the app:**
   ```bash
   flutter run
   ```
